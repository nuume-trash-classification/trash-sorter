# 0001 只做模擬，用 YOLO 真實照片評估 + webcam demo 證明 sim-to-real

- 狀態：已採用
- 日期：2026-10-22

## 背景

早期原型（[pneumatic-demo](https://github.com/nuume-trash-classification/pneumatic-demo)）用氣壓缸推桿 + 顏色規則分選寶特瓶。
正式專題要做多類別分類與機械手臂取物，但沒有實體 UR10 與輸送帶。

## 決定

- 整個系統在 Isaac Sim 裡模擬：輸送帶 + 上游俯拍相機 + UR10 吸盤，皮帶不停取物。
- 感知用只吃 RGB 的 YOLO 實例分割，訓練資料由 Replicator 自動產生。
- sim-to-real 用兩件事證明：
  - (B) 只用合成資料訓練的模型，在約 300 張真實手機照片上量 mask mAP50，並和「模擬 + 少量真實照片微調」比較。
  - (C) 即時 webcam demo。

詳細設計與成功標準見 [docs/design.md](../design.md)。

## 考慮過的其他選項

- 延續氣壓缸原型：只能處理二分類，且辨識不是學習式模型，無法展示 sim-to-real。
- 購買 / 借用實體手臂：成本與時程不允許。

## 影響

- 手臂部分的成績只在模擬中成立；報告要清楚說明。
- 「特權資訊規則」變成必要約束：最終流程只能用相機影像，不能讀模擬器真值。
- 需要團隊自己拍照、標註真實照片，並嚴格隔離測試集。
