# 架構決策紀錄（ADR）

ADR 記錄「一個重要技術決定、當時的理由、放棄了哪些選項」。之後寫報告、或有人問「為什麼這樣做」時，直接看這裡。

- 一個決定一個檔案：`NNNN-短標題.md`，編號遞增。
- 複製 [_template.md](_template.md) 開始寫。
- 決定被推翻時不要刪，把狀態改成「已被 NNNN 取代」，再寫一份新的。
